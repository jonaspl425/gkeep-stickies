# Sticky Notes Desktop

This is a raw draft of a desktop sticky notes app with early Google Keep sync experiments.

## Draft Status

This repository is an initial raw draft. Some functionality is unfinished or untested, especially account sync, note import/export, and desktop window behavior. Treat the code as a working prototype that needs security review, manual QA, and product polish before real use.

Local note data, backups, dependency folders, virtual environments, generated bytecode, credential files, and environment files are intentionally ignored and should not be committed.

## Launching Without a Terminal

For normal use, launch the packaged app from `dist/Sticky Notes-1.0.0-x64-portable.exe` or the installed Start menu shortcut. Those do not require a terminal window.

For local development from this project folder, double-click `launch-sticky-notes.vbs` to start Electron with the console hidden. You can also run `npm run start:detached`; npm will return after starting the hidden launcher.
